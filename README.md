# Devis Rénovation Concept – Refonte

## Description
Projet de refonte du site **Devis Rénovation Concept**.  
Objectif : site vitrine moderne, accessible et responsive avec formulaire AJAX et PWA.

## Structure
- `index.html` – Page d’accueil avec hero, services, galerie et tarifs
- `prestation.html` – Page des prestations avec formulaire d’avis
- `style.css` – Styles globaux, responsive et UI/UX
- `main.js` – Scripts pour menu mobile et gestion du formulaire
- `manifest.json` & `service-worker.js` – PWA
